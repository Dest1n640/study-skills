# Study skills

[English](README.md)

Шесть учебных скиллов для программирования с ручным выбором режима. Можно попросить помочь с выбором подхода, реализацией, ревью или чтением кода.

| Скилл | Поведение |
| --- | --- |
| `study-hint-normal` | Сначала выясняет твою идею, затем даёт постепенные подсказки. Код задания пишешь ты. |
| `study-hint-fast` | Даёт короткие и более прямые подсказки. Код задания пишешь ты. |
| `study-guide-normal` | Объясняет подходы и реализует конкретные части по твоим просьбам. |
| `study-guide-fast` | Помогает реализовать запрошенные части с короткими объяснениями. |
| `study-review` | Проверяет написанный код, объясняет находки и подсказывает, как исправить их самостоятельно. |
| `study-trace` | Прослеживает конкретный вход по написанному коду со ссылками на строки и схемой, когда она помогает понять маршрут. |

## Как помогает

Помощник объясняет новые понятия, причины решений и признаки применимости алгоритмов. Сравнивает подходящие варианты и рекомендует понятный метод, который пригодится в других задачах. Различает трудности с условием, алгоритмом, синтаксисом и ошибкой в коде.

Он читает относящиеся к задаче файлы и запускает доступные проверки. Разговаривает на языке ученика. Быстрый темп сокращает объяснения и делает подсказки прямее, сохраняя границы помощи.

В hint допустимы псевдокод только текущего шага, примеры синтаксиса и небольшие отличающиеся примеры. Готовые фрагменты решения задания и редактирование его реализации запрещены.

В guide просьба «сделай всё» сначала превращается в план. По последовательным конкретным просьбам агент может написать весь код. Обязательных остановок, экзаменов и доли кода, которую ученик должен написать сам, нет. Проверка понимания — только по просьбе ученика.

Review проверяет корректность, читаемость, архитектуру и производительность. Можно указать область проверки. По умолчанию он смотрит текущие изменения, а при их отсутствии проверяет весь доступный проект. Например, он покажет условие, которое считает ноль положительным, приведёт вход с неверным результатом и предложит проследить, как граничное значение попадает в подсчёт. Просьба о готовом исправлении даёт более точную подсказку. Для написания исправления явно выбери режим, который позволяет править код.

Trace следует указанному сценарию или показывает краткую карту проекта и начинает с основного маршрута, если он ясен. В [примере с заказами](evaluation/fixtures/trace/README.md) можно проследить `A7 2` от чтения аргументов в `cli.py` через расчёт в `orders.py` до сохранённого заказа и суммы `300`. Любой шаг можно разобрать подробнее. Trace проверяет важные переходы локально, когда это возможно, и объясняет, что показал запуск. При разборе исходники и тесты остаются прежними. Trace может исправить конкретную проблему по прямой просьбе, если сессия разрешает запись.

## Глубина объяснения

Помощник использует доступный контекст вместо обязательного вступительного теста. Если видно непонимание индекса, объясняет индекс на небольшом примере. Если вопрос касается сложности готового алгоритма, обсуждает сложность без повторения основ языка. «Объясни проще», «подробнее» и «основы можно пропустить» меняют глубину объяснения, а не права писать код.

Небольшой аналогичный пример показывает отдельный механизм на другой задаче. Например, перед сложной агрегацией можно разобрать, как накапливается сумма нескольких чисел. Переименование переменных в готовом решении твоего задания не считается другим примером.

## Установка и вызов

Нужен [Node.js 22.20 или новее](https://github.com/vercel-labs/skills#install-a-skill). Выполняй команды из папки своего проекта по программированию: по умолчанию скиллы устанавливаются в этот проект.

Установить один скилл из [Dest1n640/study-skills](https://github.com/Dest1n640/study-skills) для Codex:

```sh
npx skills add Dest1n640/study-skills --agent codex --skill study-hint-normal --yes
```

Установить весь набор для Codex после публикации этой версии:

```sh
npx skills add Dest1n640/study-skills --agent codex \
  --skill study-hint-normal study-hint-fast study-guide-normal study-guide-fast study-review study-trace \
  --yes
```

Команды используют готовый [Skills CLI](https://github.com/vercel-labs/skills/blob/main/docs/commands.md#skills-add); `--yes` пропускает подтверждения установщика. Для Claude Code замени `--agent codex` на `--agent claude-code`. Для установки другого отдельного режима замени `study-hint-normal` на его имя из таблицы выше.

Для интерактивной установки запусти `npx skills add Dest1n640/study-skills` и выбери своего агента и нужные из доступных `study-*`. Явный выбор позволяет установить учебные скиллы без служебных `openspec-*`.

Из локальной копии репозитория:

```sh
npx skills add . --agent codex --skill study-review
npx skills add . --agent codex --skill study-trace
npx skills add . --agent codex --skill study-hint-normal study-hint-fast study-guide-normal study-guide-fast study-review study-trace
```

Проверки локальной установки и поведения в Codex описаны в [результатах](evaluation/RESULTS.md). Удалённая установка этой версии не проверялась. После установки перезапусти агента или обнови обнаружение скиллов, если этого требует клиент.

Вызов в Codex, например, `$study-trace Проследи, как аргументы A7 2 превращаются в заказ` или `$study-review Проверь изменения в парсере`. В Claude Code — `/study-trace` и `/study-review`. Для смены режима явно выбери другой скилл или сообщи, что заканчиваешь учебный режим.

Инструкции написаны на английском. Ручное включение задано отдельными настройками Codex и Claude Code; другие агенты могут интерпретировать их иначе. Claude Code не тестируется в первой версии. Для создания и публикации файлов регистрация Claude не нужна.
