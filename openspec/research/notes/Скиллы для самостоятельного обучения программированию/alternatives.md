# Готовые учебные режимы и альтернативы

## Подходит ли официальный Learning от Anthropic?

### Takeaway
Официальный Learning существует, но помогает участвовать в работе агента, а не оставляет всю реализацию человеку. Это полезный образец совместного обучения, но не готовая замена четырём запрошенным скиллам.

### Cited Findings
- Документация Anthropic описывает Learning как режим, где Claude сам выполняет рутинную реализацию, оставляет человеку небольшие участки с реальным проектным выбором, помечает их `TODO(human)`, ждёт выполнения, затем продолжает. Explanatory добавляет объяснения к обычной работе агента. Это не запрет на написание решения. Документация также прямо различает инструкции и гарантии: output style не обеспечивает абсолютное соблюдение поведения. Для отдельных типов задач Anthropic указывает skills, для обязательных операций — hooks. — [Официальная документация](https://code.claude.com/docs/en/output-styles)
- Официальный плагин `learning-output-style` внедряет контекст через SessionStart; автоматически включается в каждой сессии при установленном плагине. README описывает человеческие вклады примерно по 5–10 строк и прямую реализацию агентом шаблонного кода, конфигурации и CRUD. — [README плагина](https://github.com/anthropics/claude-plugins-official/tree/main/plugins/learning-output-style)
- Реальные инструкции hook требуют подготовить файл, сигнатуру, контекст и TODO перед запросом вклада пользователя. Они ориентированы на выборочные содержательные вклады, а не на отказ выполнить всё учебное задание. — [Исходник session-start.sh](https://raw.githubusercontent.com/anthropics/claude-plugins-official/main/plugins/learning-output-style/hooks-handlers/session-start.sh)
- Для плагина опубликована Apache License 2.0; при буквальном заимствовании исходных файлов следует сохранить соответствующие сведения о лицензии. — [LICENSE](https://raw.githubusercontent.com/anthropics/claude-plugins-official/main/plugins/learning-output-style/LICENSE)

### Inferences
- Для пользователя полезно взять принцип «содержательная часть остаётся учащемуся» и привязку объяснений к реальным файлам, но изменить главное правило: даже guide пишет только явно запрошенную небольшую часть, hint не пишет решение вообще.
- Установка SessionStart-плагина не соответствует желанию включать один из четырёх режимов явно через `$`; перенос коротких педагогических идей проще установки плагина.

### Gaps
- Плагин и режим не устанавливались и поведенчески не тестировались. Вывод сделан по документации и реальным инструкциям.
- В README есть историческое слово `unshipped`, тогда как текущая документация описывает встроенный Learning. В отчёте лучше не повторять историю выпуска и не заявлять, что Learning отсутствует.

## Есть ли готовые открытые стили с нужными границами?

### Takeaway
Есть короткие Socratic-стили и более развитые учебные плагины. Название «Socratic» само по себе не означает строгий запрет: проверенные исходники содержат прямые пути к выдаче ответа.

### Cited Findings
- `nattergabriel/claude-code-output-styles/output-styles/socratic.md` предлагает вопросы, адаптацию к уровню, небольшие подсказки и прямое объяснение недостающих основ. При явной просьбе прекратить вопросы разрешает писать код и выдавать прямой ответ. Разрешено читать проект и выполнять команды ради точных вопросов. В frontmatter стоит `keep-coding-instructions: false`. — [Сам файл стиля](https://github.com/nattergabriel/claude-code-output-styles/blob/main/output-styles/socratic.md)
- Репозиторий объявляет MIT-лицензию и распространяет стили как файлы в `.claude/output-styles`, а не как четыре программных учебных skill. — [Репозиторий](https://github.com/nattergabriel/claude-code-output-styles)
- Другой короткий `arvindand/agent-skills/output-styles/socratic.md` предписывает один конкретный вопрос за ход, но содержит явный escape hatch: по «just tell me» немедленно отвечать прямо. — [Сам файл](https://github.com/arvindand/agent-skills/blob/main/output-styles/socratic.md)
- `Flagrare/llm-tutor` — учебный плагин с тремя персонажами, слоями подсказок, прогрессом, XP и ограниченной внутренней валютой обращений. README называет проект alpha и указывает на отдельный облегчённый `flagrare:tutor` в другом репозитории для тех, кому не нужна эта система. Лицензия проекта MIT. — [Репозиторий](https://github.com/Flagrare/llm-tutor)
- Реальный стиль Cipher имеет лестницу подсказок вплоть до раскрытия ответа; на повторное требование «дай ответ» допускает его выдачу. Разрешает писать инфраструктурный код и оставлять человеку `TODO(you)` в содержательной части. Педагогический темп зависит от персонажа; это не запрошенная матрица «право писать × скорость». Внутри файла есть напряжение между разрешённым Reveal и жёсткими формулировками об отсутствии утечки решения. — [Cipher.md](https://github.com/flagrare/llm-tutor/blob/main/plugins/llm-tutor/output-styles/cipher.md)

### Inferences
- Готовые стили полезны как образцы спокойных вопросов, постепенного усиления подсказок и перехода к объяснению основ. Взять их без изменений означает сохранить возможность получить полный ответ по повторной просьбе, что расходится с требованиями пользователя.
- Полный llm-tutor избыточен: XP, валюта, персонажи и трекинг пользователь не запрашивал. Различие голосов и педагогического давления не равно различию обычного и быстрого темпа.

### Gaps
- Эти стили проверены чтением исходников, не в живых учебных сессиях.
- Не проверена их фактическая работа в Codex; это Claude Code output styles, и их нельзя описывать как готовые `$`-скиллы Codex.
- Облегчённый `flagrare:tutor` передан исследователю строгих скиллов; здесь его исходник не исследован, чтобы избежать дублирования.

## Есть ли смысл создавать свои четыре скилла?

### Takeaway
По проверенным альтернативам — да: имеет смысл написать небольшие собственные инструкции, используя известные учебные механики. Это адаптация существующей педагогики к конкретным границам, а не разработка новой платформы.

### Cited Findings
- Официальный Learning сочетает самостоятельную реализацию агентом с выбранными пользовательскими вкладами; проверенные открытые Socratic-стили допускают прямой ответ после просьбы. — [Learning](https://code.claude.com/docs/en/output-styles); [Socratic nattergabriel](https://github.com/nattergabriel/claude-code-output-styles/blob/main/output-styles/socratic.md); [Socratic arvindand](https://github.com/arvindand/agent-skills/blob/main/output-styles/socratic.md)

### Inferences
- Полное совпадение требований в моей выборке не найдено. Это не утверждение, что такого скилла нигде не существует.
- Для будущих четырёх режимов важно описать размер совместного шага и момент остановки. Иначе guide может формально разбить всё задание на функции и написать их подряд сам.
- Быстрый темп должен менять краткость и прямоту помощи, сохраняя границы авторства. В hint псевдокод допустим, но его подробность следует согласовать: полный псевдокод всей задачи может свести самостоятельность к переводу синтаксиса.
- Смысл своей реализации — явный `$`-выбор, единая граница «никогда не выполнять всё задание за учащегося», два темпа, работа с реальными файлами и обязательные проверки. Для этого достаточно инструкций без XP, hooks, обязательных внешних сервисов и установок чужих плагинов.

### Gaps
- Не проведено сравнение качества обучения или надёжности соблюдения границ на реальных моделях. Инструкции не следует представлять как технически непреодолимый запрет.
- Вывод ограничен найденными и прочитанными первичными источниками на дату исследования, 17 ноября 2026 года.
