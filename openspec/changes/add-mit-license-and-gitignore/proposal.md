## Why

Проект готовится к публичному распространению, но явной лицензии и правил исключения локальных артефактов пока нет. Пользователь выбрал MIT.

## What Changes

- Добавить LICENSE с MIT для оригинальных материалов проекта и указать лицензию четырёх продуктовых скиллов.
- Сохранить исходное уведомление OpenSpec для сгенерированных служебных скиллов.
- Добавить минимальный .gitignore для локальных секретов, окружений, кэшей и временных файлов; сохранить учебные материалы, OpenSpec и доказательства проверок.
- Обновить оба README и текущий статус решения о лицензии.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `distribution-validation`: явная лицензия продукта и правила хранения локальных артефактов.

## Impact

LICENSE, THIRD_PARTY_NOTICES.md, .gitignore, два README, метаданные четырёх SKILL.md и DECISIONS.md. Автор в copyright — Dest1n640 из конфигурации Git, год — 2026. Чужие материалы не перелицензируются. Отслеживаемые файлы не удаляются из индекса, история Git не переписывается. Поведение наставников не меняется.

Полный LICENSE также включается в каждую из четырёх самостоятельных папок скиллов: установка одного режима должна сохранять уведомление.
