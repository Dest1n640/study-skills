## Context

См. proposal.md. MIT выбрана пользователем. В репозитории есть оригинальные учебные скиллы и отслеживаемые OpenSpec-помощники с upstream MIT: Copyright (c) 2024 OpenSpec Contributors. Решение затрагивает README, метаданные и уведомления стороннего кода, поэтому границы лицензирования фиксируются отдельно.

## Goals / Non-Goals

**Goals:** стандартный LICENSE, последовательные метаданные, сохранение чужого уведомления и проверяемые ignore-правила.

**Non-Goals:** изменение поведения, удаление отслеживаемых данных, переписывание истории, исключение исследований и результатов проверок.

## Decisions

- LICENSE: стандартный MIT, Copyright (c) 2026 Dest1n640; имя взято из Git. THIRD_PARTY_NOTICES.md сохраняет полный исходный MIT OpenSpec для служебных файлов. Корневой MIT не заменяет права на сторонние цитаты и внешние ссылки.
- Четыре продуктовых SKILL.md получают license: MIT. Старые снимки проверок и архивы не меняются: это исторические свидетельства.
- .gitignore содержит только локальные артефакты: системный мусор, Python/Node окружения и кэши, .env с исключениями для шаблонов, editor backup и evaluation/.local/. Общие *.log, .agents/ и evaluation/runs/ не исключаются.
- Уже отслеживаемые файлы остаются в индексе. Удалять их через git rm --cached нет причины.

## Risks / Trade-offs

- Чужой copyright потеряется при добавлении корневой лицензии → сохранить полное upstream-уведомление.
- Ignore скроет полезные материалы → проверить положительные и отрицательные примеры через git check-ignore --no-index.
- Старые записи о невыбранной лицензии могут вводить в заблуждение → обновить текущие README и решение, сохранив датированные результаты/снимки.

Полный LICENSE также включается в каждую из четырёх самостоятельных папок скиллов: установка одного режима должна сохранять уведомление.
