## Why

Согласованные правила сохранены, и три базовые спецификации валидны. Однако часть уже существующих правил не покрыта сценариями, результаты пробных прогонов нельзя повторить по материалам репозитория, а установка из корня может предложить служебные OpenSpec-скиллы вместе с учебными режимами.

## What Changes

- Дополнить контракт режимов: явное завершение учебного режима, широкое задание из одной функции, проверка понимания по запросу. Это уточнения уже написанных инструкций, а не новая педагогика.
- Предложить установку с явным выбором четырёх `study-*` и проверить этот путь в отдельном временном проекте.
- Сохранить небольшие тестовые проекты, точные запросы, критерии оценки и фактические артефакты будущих Codex-прогонов.
- Сравнить normal/fast на одинаковых входных данных и отдельно проверить переключение режимов. Непроверенное оставить явно непроверенным.

Подтверждённые решения hint/guide сохраняются. Формат хранения проверок и способ ограничения установки — предлагаемые технические решения этого change. Бренд, лицензия и адрес репозитория остаются открытыми.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `study-modes`: дополнить наблюдаемые сценарии выбора/завершения режима и существующих границ guide.
- `distribution-validation`: ограничить рекомендуемую установку продуктом и установить проверяемый минимальный формат доказательств новых прогонов.

## Impact

Будут затронуты `evaluation/`, оба README и соответствующие спецификации. Учебные SKILL.md меняются только при обнаруженной проверкой ошибке; заранее переписывать их не требуется. Разработка затрагивает все четыре режима, но не добавляет режимов, обязательных квизов или доли кода ученика.

Новые runtime-зависимости, свой установщик, изменение служебных OpenSpec-скиллов, публикация, выбор лицензии и испытания Claude Code не входят в change. Планирование само по себе не выполняет установку или поведенческие прогоны.

## Уточнение исправления hint

Оставшаяся задача 4.1 уточняет трактовку прямых просьб написать код внутри hint и взаимодействие с другими coding-скиллами. План проверок и ограничения причинного вывода описаны в design.md.

Пользователь подтвердил техническое дополнение: Codex hint запускается в read-only с never, переход в guide описывается через resume с workspace-write/on-request и явный выбор скилла. Ограничения выдачи готового кода в чате остаются инструкциями; глобальные настройки клиента не меняются.
