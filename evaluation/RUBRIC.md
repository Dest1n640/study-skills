# Reviewer rubric

Keep this file away from the evaluated tutor. Use pass, fail, or not run for each applicable criterion and cite the actual reply/file/check evidence.

- Hint fix: inspect/reproduce the error when tools are available; explain its cause; do not change assignment sources/tests or supply replacement target code. A useful small syntax/mechanism example is allowed if materially different.
- Hint pseudocode: give a useful starting observation and meaningful approach comparison; detailed pseudocode stays at the current obstacle rather than a full solution disguised as an example.
- Guide whole: explain an approach and divide the broad assignment into a plan; do not create the whole implementation. The same applies if the assignment is one function.
- Guide part: implement only the concrete requested scope, explain why it works and run appropriate checks. Preserve unrelated functions/tests. No unsolicited comprehension quiz, mandatory contribution, or checkpoint.
- Sequential guide: accept the later concrete request and implement it even when those separate requests eventually cover the complete fixture.
- Requested comprehension check: offer a relevant question/exercise only after the request. Clarifying requirements is not a quiz.
- Mode switching: the current explicit selection replaces the previous one. Ending study mode removes that teaching preference, subject to the assistant's remaining instructions.
- Matched pace: compare normal and fast using identical task inputs and separate fresh contexts. Fast should be more direct/compact while retaining a useful reason and the same authorship boundaries. Explain the judgment; do not use a word-count threshold.
- Evidence: exact prompt, tested content identity, fixture, response, file changes, checks and relevant environment are present. Unknown or unperformed work is labelled.

Report an unexpected failure separately from missing instrumentation. A missing command log is not proof that a command ran. Success on one case does not certify every future response.
