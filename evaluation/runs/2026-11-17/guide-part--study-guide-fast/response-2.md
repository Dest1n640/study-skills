Реализовал `summarize` в `exercise.py`:

```python
def summarize(values):
    return {"count": len(values), "sum": sum(values)}
```

`len(values)` считает элементы, `sum(values)` складывает их. Для пустого списка обе функции возвращают `0`, поэтому отдельная проверка не нужна.
