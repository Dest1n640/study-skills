Реализовал только `parse_numbers` в `exercise.py`:

```python
def parse_numbers(text):
    return [int(item) for item in text.split(",")]
```

`split(",")` разбивает строку на элементы, а `int()` преобразует каждый в целое число и допускает пробелы вокруг него. Пустая строка, пустой элемент (включая пробелы) и нецелое значение вызывают `ValueError` при преобразовании. Отдельные проверки и `strip()` здесь не нужны.
