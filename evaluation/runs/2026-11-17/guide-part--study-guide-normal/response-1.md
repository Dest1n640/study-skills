Реализовал `parse_numbers` в `exercise.py`:

```python
def parse_numbers(text):
    return [int(part) for part in text.split(",")]
```

`split(",")` разделяет строку на элементы, а `int()` превращает каждый элемент в целое число. Пробелы по краям и знак числа он обрабатывает сам: `" 1, -2, 0 "` даёт `[1, -2, 0]`.

Отдельные проверки здесь не нужны: пустая строка после разделения даёт `[""]`, а пустой элемент — `""` или пробелы. Для них, как и для `"2.5"`, `int()` выбрасывает нужный `ValueError`. Фильтровать пустые элементы нельзя: тогда ошибочный ввод мог бы пройти незаметно.
