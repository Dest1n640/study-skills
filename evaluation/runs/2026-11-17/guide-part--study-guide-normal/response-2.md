Реализовал `summarize` в `exercise.py`:

```python
def summarize(values):
    return {"count": len(values), "sum": sum(values)}
```

`len(values)` возвращает число элементов, `sum(values)` складывает их. Например, для `[1, -2, 4]` получаем `{"count": 3, "sum": 3}`. Для пустого списка обе встроенные функции возвращают `0`, поэтому отдельная ветка `if` не нужна.

Можно было посчитать всё вручную в цикле, но встроенные функции короче и прямо выражают задачу. Суммирование проходит по списку один раз: время — O(n), дополнительная память — O(1).
